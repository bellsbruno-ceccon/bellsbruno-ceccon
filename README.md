## ✨ Sobre mim

Sou **Desenvolvedora Full Stack Java em transição de carreira**, depois de mais de 8 anos construindo experiência em negócios, negociação e relacionamento com clientes.

Minha virada para a tecnologia ganhou forma em uma formação intensiva de 3 meses pela **Generation Brasil**, com desenvolvimento prático em **Java, Spring Boot, APIs REST, SQL e Git**.

Hoje, inicio minha trajetória como profissional júnior trazendo algo que o código sozinho não ensina: **visão de negócio, comunicação e capacidade de transformar necessidades complexas em soluções com valor real**. Vejo esta nova etapa como uma oportunidade de expandir meu potencial técnico, conectando desenvolvimento, negócios e IA para criar soluções cada vez mais inteligentes e relevantes.
